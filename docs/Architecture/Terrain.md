# Terrain and the map floor

- THE FLAT MAP FLOOR IS ONE MESH (`World/Map/Ground`, `scripts/world/ground.gd`): a StaticBody3D on layer 20 with `metadata/surface = "sand"`, a 120x120 `PlaneMesh` child (subdivided 600x600 so the sand-tracks shader has verts to displace; the material is that shader now, `sand_color` = the old albedo) and a `BoxShape3D` under it (`fit_collision()` sizes the box off the plane, so resizing the plane is the only edit). It replaced 1600 identical y0 GridMap tiles — that rectangle IS level-0 land now, and `columns()` reports it in terrain-column units (read off the sibling map's `cell_size`, so the two grids cannot drift). The albedo is the exact pixel the kit's `hill_top_e_center` sampled, so nothing changed colour. The GridMaps keep only what stands ABOVE it: 39 floor cells and the walls/skirt.

- Terrain (TWO GridMaps, `game.tscn` `World/Terrain` = walls + `World/TerrainFloors` = floors): KayKit Nature Pack Hill kit (CC0, credit Kay Lousberg) — `assets/meshes/environment/terrain/hills_library.tres`, 70 plain items shared by both maps (id contract with painted maps — only append, never renumber: base kit 0-39 alphabetical — `hill_top_*` flat tops surface-at-y0, `hill_cliff_*` 2m + `hill_cliff_tall_*` 4m walls, A-I compass naming — then carved ridge pieces from `_tools/asset_extractor/extract_ridges.gd`: strips 40-45, ends 46-57, bends 58-69). Grid math: `cell_size (3, 2, 3)` + `cell_center_y = false` → paint a piece at the cell whose BOTTOM plane is its walking surface (flat ground at cell y=0 = world y 0); meshes may overhang their cell (tall cliffs span 2). Both maps: `collision_layer = 20` (walls|ground: bodies stand on it AND it blocks enemy vision LOS), `metadata/surface = "grass"` for hit/footstep `SurfaceData` lookups (raycasts report the GridMap NODE as collider; one tag map-wide). The height field is the GROUND MESH's footprint (every column in it starts at level 0) RAISED by the floors map (`autotiler.gd` `derive(floors, ground_rect)`: max `hill_top_*` cell per column). The FLOORS map therefore holds only what sits above the mesh — terrace shelf floors inside wall columns and each column's top; the WALLS map holds cliffs and the below-y0 void-edge skirt. `column_pieces` skips its y0 tile for any column inside `p_ground` (that IS the mesh) but still emits one outside it, so painting land beyond the plane is not silently a hole. Any floor shape under any wall with no baked combos — shelf floors rim wherever the surface they continue stops (`floor_shape`/`floor_at`: over a drop or against a shelf-less wall column, two-cells-out sensitivity is why `affected_columns` is ring 2), so narrow stadium ridges keep their strip/end/bend profiles into hillsides, pillar stems, and map edges. A STADIUM-topped column (strip/end/bend) extends that silhouette through every wall slot instead of per-slot shapes — its narrow walls sit inset from the cell boundary, so a raised neighbor's mass can never seal its faces the way full-width pieces seal each other's (shelves are placed in a separate pass because stadium walls always tall-merge past terrace slots). LEVEL EDITING: the `grid_map_painter` editor plugin (`addons/grid_map_painter/`) adds a "Ground Brush" + Raise/Lower toggles to the 3D toolbar when EITHER terrain GridMap is selected (the plugin resolves the sibling pair by node name — keep them named `Terrain`/`TerrainFloors` under the same parent) — Raise gives a VOID cell flat ground and a ground cell +1 level, Lower drops a level (over the ground mesh it STOPS at 0, since there is no hole to lower into; beyond the mesh level 0 still erases back to void), dragging spreads the stroke's target; piece choice is derived from the height field by `autotiler.gd` (pure, probe- and fuzz-tested), so never hand-pick pieces. The painter resolves a sibling named `Ground` for the level-0 rect — without one it falls back to reading y0 tiles, exactly as before. 1-wide LINES connect with the carved ridge pieces (`*_strip_ns/ew` opposite-edge cells, `*_end_n/s/w/e` dead ends, `*_bend_a/c/g/i` L-turns — carved from the stadium prefabs `Hill_4x2x2/4x2x4`: welded top/cliff islands split, clipped at the straight-run junctions, stretched to cell pitch, cliff roots extruded, cut faces normal-welded + capped so seams mate flush; bends = round-cap quadrant + two 45°-mitered half-strips; rerun the extractor before the library builder if the source prefabs change); lone single cells stay cap + pillar wall, the kit's intended look. An outer-corner cell whose opposite diagonal ALSO drops away is a 1-wide bend (`BEND_DIAGONALS`) — real plateau corners keep the full-width piece; T-junctions and 4-way crossings in 1-wide networks still fall back to full-width sides (known limit, no carved piece yet). Rebuild the library after re-extraction with `_tools/asset_extractor/build_terrain_library.gd`. Roads are SPLINES now, not a third GridMap — see Traffic above.

Props (trees/rocks/bushes/grass) are NOT GridMap items — scenes under `scenes/props/` (tree/rock = StaticBody3D on walls layer 4, bush = bare mesh) over meshes in `assets/meshes/environment/props/`. LEGACY: the TerraBrush addon is deleted; `data/terrabrush/` and `assets/textures/terrains/` linger on disk, and the `terrain-set` skill manages those texture sets if TerraBrush ever returns.
